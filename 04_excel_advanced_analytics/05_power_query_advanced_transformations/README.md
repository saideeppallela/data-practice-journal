# 📖 Introduction

This repository documents my learning focused on **Power Query Advanced Transformations** in Microsoft Excel.

The objective was to understand how business data is prepared before reporting and dashboard creation by combining multiple datasets, creating calculated columns, and generating meaningful summaries.

Rather than practicing isolated Excel features, I worked through a complete data transformation workflow similar to what Data Analysts perform in real business environments.

---

# 🎯 Learning Objective

The goal of this exercise was to strengthen my understanding of Power Query by learning how to:

- Import multiple datasets
- Merge related tables
- Append transaction data
- Create calculated business metrics
- Transform date fields
- Generate summary tables
- Build a clean dataset ready for analysis

---

# 💼 Business Scenario

A retail business stores sales transactions across different periods while maintaining product details separately.

Before analysis, the datasets need to be combined, cleaned, enriched, and summarized to support business reporting.

This exercise demonstrates that workflow using Microsoft Excel Power Query.

---

# 📂 Dataset

| Table | Description |
|--------|-------------|
| Sales_Transactions | Sales transaction records |
| Product_Master | Product information including category and cost price |
| Q2_Transactions | Additional quarterly sales transactions |

---

# 🔄 Workflow

## 1. Import Data

- Imported Excel Tables into Power Query
- Loaded data for transformation

## 2. Merge Queries

Merged Sales Transactions with Product Master using a **Left Join**.

Expanded:

- Product Name
- Category
- Cost Price

---

## 3. Append Queries

Combined:

- Sales Transactions
- Q2 Transactions

Created:

**All_Transactions**

---

## 4. Custom Columns

Created:

- Revenue
- Profit

using business calculations.

---

## 5. Date Transformation

Extracted:

- Month Name

from the transaction date.

---

## 6. Group By Analysis

Generated:

- Category Revenue Summary
- Customer Transaction Count
