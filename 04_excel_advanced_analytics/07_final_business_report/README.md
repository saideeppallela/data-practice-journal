# 📌 The Challenge

Business data is valuable only when decision-makers can understand it quickly.

Given a retail sales dataset containing thousands of transactions, the challenge was to create a dashboard that enables management to answer key business questions without manually analyzing the raw data.

---

# 💡 My Approach

Instead of filling the dashboard with every available metric, I focused on the information an executive would most likely need first.

✔ How much revenue has the business generated?

✔ Which region performs the best?

✔ Is revenue increasing over time?

✔ Can users filter insights instantly?

Every visual and KPI was designed to answer one of these questions.

# ⚙️ How I Built It

- Organized raw data into structured Excel Tables
- Created KPI calculations on a dedicated **Calculations** sheet
- Built PivotTables to summarize business metrics
- Designed PivotCharts for visual analysis
- Connected slicers for interactive filtering
- Structured the workbook into **Raw Data → Calculations → Dashboard**

# 🌱 What This Project Taught Me

One of the biggest lessons from this project wasn't creating charts—it was deciding **what not to show**.

A dashboard becomes more valuable when it highlights the few metrics that support faster decisions instead of displaying every available number.

This project strengthened my understanding of organizing data, designing dashboards with a business purpose, and presenting insights in a simple, interactive format.
